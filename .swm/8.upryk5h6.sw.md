# Operations and Overnight Jobs

## Job Contract
Each job should expose its profile, input scope, dependency checks, write mode,
identify command, profile, run ID, start/end time, records seen, created,
updated, skipped, failed, and resumed, plus sampled verification. Job names
should describe the owning domain rather than hiding several writers behind a
## Operating Model

## Validation

Start with `scripts/run_overnight.py --list-jobs`, then use `--help` and
`--profile safe --preflight`. Run `tests/test_run_overnight.py` and review the
generated state/log artifacts before any bounded writer execution.
