Where iLit is going

iLit is a personal proof of concept. It is not a finished product. Today it is a working library of immigration decisions that you can search. There are many significant improvements still to come, and this page is a preview of them.

Built to become an agency tool, not a public website

iLit is public today so that people can see it and try it. That is not where it is meant to end up. The goal is an official CBSA tool, run by the CBSA, for CBSA staff. It was built with that in mind, and there is a plan to get there in three steps.

The same software moves at each step. Moving does not mean rebuilding.

  • Easy to move. Live The site is packaged so it can be picked up and placed on another computer. It does not depend on any outside AI service to run, and pasted text is never saved.
  • Only public information. Live The library holds public case law and what has been worked out from it. Nothing private is in it today.
  • The middle step has a plan. Tested A rented private server in Canada would cost about CA$32 a month. Nothing is bought yet.
  • The last step is a conversation, not a build. Concept It would need the CBSA to approve it and to run it on its own systems.

It works on text, so it can work on any document

iLit does not need neat, organized data. It simply reads text, the way a person would. Court decisions came first because they are public. The same reading works on any document, wherever it came from.

What could be included, in theory, if the agency adopted it:

Deferral decisionsSearched together with the published decisions.
Private ID decisionsDecisions that are never published, read the same way.
ENF manuals and internal guidanceLinked to the decisions that apply them.
Drafts of MOAs and RMOAsChecked against the library, as a draft is today.

This is where the real power would come from. A public website can only hold public material. A tool inside the agency could put the public case law and the agency's own files in one place, so a single search covers both. That is a concept. It would need CBSA approval, and a private AI that stays inside the agency, which the next section explains.

  • What supports it. Tested Checking a pasted draft already works on plain text with no special formatting. A 40,000 character draft that cites 68 cases was fully checked in about one second.
  • What does not support it yet. Nothing has been tried on internal documents. Every test used public decisions and sample drafts, so how well it would work on internal documents is unknown.

A private AI that stays in the building

An AI model is a program that reads and writes text. Most are rented from a technology company, so your text travels over the internet to their computer. A private model is the same kind of program, running on a computer the agency owns. Nothing leaves the building.

Why a private AI is worth having

Resilient

It keeps working when the AI market changes. A model that has been downloaded does not stop if a company raises its prices, retires a model or changes its rules.

Does not depend on any company

If an AI company goes bankrupt, is sold or shuts a service down, nothing changes for the agency. The model files and the computer stay where they are.

Controlled inside the agency

The agency decides who can use it, what it can see and when it is updated. It can be paused or switched off at any time.

Stays the same until you change it

The version is fixed. Results do not shift because a supplier quietly updated its model.

Nothing leaves the building

Documents and questions are never sent to an outside company.

A cost you can predict

There is no fee for each use. The cost is the computer and its electricity.

What it takes

A strong computer

One machine with a powerful graphics card, owned by the agency. It is a one-time purchase, not a subscription.

A model downloaded once

Free, openly shared models can be downloaded and run offline. After that, no internet connection is needed.

Easy to swap

Better models keep appearing. The agency could change to a newer one without changing the site.

How the site would use it

The site already follows one rule that makes this possible: AI reads each decision once, when it is added, and the result is saved. Searching uses no AI, and nothing you type is sent to one. A private model would do that reading inside the agency. It could also read the agency’s own documents, which a rented AI should never be sent. The specific things it could do are listed under Local AI integration, below.

What it asks in return. A computer to buy and look after, and models that are somewhat smaller than the very largest rented ones. Those are real costs, and the agency would be choosing them in exchange for the benefits above.

So far the AI reading on the site was done on public case law only. A private model has not been set up. Everything about it here is a concept.
