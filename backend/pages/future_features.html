Roadmap · a future-state goal for iLit

Future features and the work still to do

This page describes where iLit could go next and what stands in the way. Each item says what exists today, what is left to build and what it depends on. The pictures are concept mock-ups with invented sample data, not screenshots of working features.

The assumption behind it. The AI features assume the agency can run its own AI model on its own computers. The site’s normal search does not use AI at all, and nothing a person types is sent to an outside AI service. Where AI helps, it would run on that on-premises model or when decisions are added to the library, and its work would be stored as data that links back to the source paragraph.

Judge and decision-maker insights

Partly built

How a judge or Board member has ruled on a given issue, with the count shown beside every figure and a warning when it is small.

Concept mock-up, not built yet · invented sample data

Sample decision-maker view · issue: procedural fairness

Decision-maker ABased on 12 casesMinister lost 5 · won 6 · unclassified 1
Decision-maker BOnly 3 cases, too few to read

Every figure shows its case count. These are descriptions of past decisions, not predictions.

What exists today

Judge Profiles are live: outcomes by issue with the full count and the unclassified decisions shown. Judge names are written many ways in the sources, so some duplicate profiles remain. The judge is extracted for only part of the Federal Court library and for no French decisions. RPD decision-maker names are blank.

Still to do

  • Finish name cleanup across all courts
  • Extract decision-makers for the gaps (French, RPD)
  • Reach the outcome accuracy needed before any rate is quoted

Depends on

  • Reliable decision-maker names
  • Outcome accuracy close to complete (a reviewed gold set of 587 cases exists)

Phase 2 · assumes an on-premises AI model

The rule holds: normal search keeps working with no AI. Where AI is used, it runs on the agency’s own computers or when decisions are added, and its output is stored as data that links back to the source.

4

Local AI smart search

Concept only

Ask a question in plain words and get the paragraphs that mean the same thing, with the reason each matched. It would run on the agency’s own computer, so no question leaves the network.

Concept mock-up, not built yet · invented sample data
What has the Federal Court said when an officer relies on concerns that were never put to the applicant? Search

Best matching passages · 3 of 41 shown

FCExample v. Canada (Citizenship and Immigration), 2021 FC 412Strong match

… the officer drew an adverse inference from information the applicant had no chance to answer, and that is a breach of procedural fairness …

Matched on meaning: “concerns never put to the applicant” ≈ “no chance to answer” (para 27)
FCSample v. Canada (Citizenship and Immigration), 2019 FC 1130Strong match

… extrinsic evidence not disclosed before the refusal, on which the decision turned …

Matched on meaning: “relies on concerns” ≈ “decision turned on” (para 15)
RPDRPD file VB7-00000 (2022)Related

… credibility questioned using a document first raised in the reasons … (para 41)

What exists today

Search by name, citation or phrase works with no AI, and plain sentences now return quickly. A paragraph search table exists but is empty of scores, and semantic search is paused. Nothing on the live site sends a question to an AI service.

Still to do

  • Choose and test a local embedding model on real questions
  • Fill the paragraph fingerprints at ingest
  • Show the matching paragraph and the reason for each result

Depends on

  • An on-premises AI model
  • Computer capacity to build the fingerprints once
5

Advanced citation treatment

Concept only

Beyond who cites a case: how each citing decision treated it (followed, applied, distinguished, questioned, criticised), with a plain-language line for each and a warning when the tide turns.

Concept mock-up, not built yet · invented sample data

Example v. Canada (Citizenship and Immigration), 2019 FC 100 · cited by 214 decisions

Followed 61%Applied 20%Distinguished 11%Questioned 5%Criticised 3%

What each citing case did

FollowedSample v. Canada (MCI), 2023 FC 77, para 34 Summary: Adopts its test for a sponsorship refusal. Open paragraph
DistinguishedTest v. Canada (MCI), 2022 FC 905, para 51 Summary: Not followed: the applicant had notice. Open paragraph
CriticisedDemo v. Canada (MCI), 2020 FC 1042, para 18 Summary: Reasoning too broad after later guidance. Open paragraph

What exists today

Citation Intelligence is live: which decisions cite a case, how that changed over time, and the outcomes of the citing decisions. A cleaner citation link set is built in side tables but the site has not been switched to it. Indicators of possible later developments are a short hand-edited list, not complete. Treatment labels exist only as an offline trial.

Still to do

  • Switch the site to the refined citation links
  • Label treatment for each citing paragraph, with a visible “how assigned” line
  • Write the one-line summaries at ingest and review a sample by hand

Depends on

  • An on-premises AI model for the summaries
  • Human review of a labelled sample before anything is shown

What exists today

Live Analysis reads an uploaded memorandum in memory and lists the cases and statutes it cites, with nothing stored. It does not yet identify arguments or suggest replies. The case structure layer that splits a decision into parts exists.

Still to do

  • Identify arguments and match them to the reply
  • Rank suggested reply cases using citation treatment
  • Test on real memoranda with lawyers reviewing the suggestions

Depends on

  • An on-premises AI model
  • Citation treatment (item 5) for the ranking

What exists today

Still to do

  • An on-premises deployment
  • Security review and approval
8

Immigration Division and Appeal Division coverage

Concept only

Decisions of the ID and the IAD searched next to the Federal Court cases that review them. This matters most for hearings work.

What exists today

None. The tribunal decisions are not in the public datasets used so far, and the library holds none of them.

Still to do

  • Confirm a source and the terms of use
  • Import and tag them the same way as other decisions
  • Link them to the judicial review decisions that cite them

Depends on

  • An agency data feed (see item 7)
  • Licence and privacy approval

Smaller gaps on the list

Trust and accuracy

Outcome coding is being re-checked against a reviewed set. Some outcomes, such as the Supreme Court’s Vavilov, are known to be wrong on the live site until that finishes.

Save, export and hand off

Saved issues exported as a case list (CSV or Word), and a one-page issue brief that shows the number of decisions behind each figure.

Reader improvements

Paragraph citation shading, short extractive case summaries that point to the holding paragraph, and a fuller markup mode.

Hosting and backup

The database and site run on one personal computer and there is no backup yet. The long-term plan is a hosted Canadian cloud, and a backup should come first.
