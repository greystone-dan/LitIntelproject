# Data classification

The sensitivity labels below are **proposed for the department to decide; not
a determination**. Classification must consider the actual source, context,
combination of fields, intended use, and applicable departmental policy. The
repository does not make that decision.

## Limits

- “Public” describes a proposed label for the source category, not a finding
  that every record is free of personal information or permitted for every use.
- The optional application access gate and request-audit log are disabled
  unless their runtime settings enable them. Their live settings are not
  available in this repository checkout. [docs/CONFIGURATION_REFERENCE.md:50-65](../CONFIGURATION_REFERENCE.md#L50-L65)
- Upload source code does not prove absence of multipart spooling, browser
  copies, proxy logging, backups, or operating-system temporary files.
