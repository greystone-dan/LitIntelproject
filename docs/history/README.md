# Historical Documentation Archive

This folder stores historical project handoff and summary documents.

## Purpose

Use this directory for documents that preserve implementation history or decision context but are not the current operational source of truth.

## What belongs here

- AI handoff snapshots
- stage summaries
- one-time project notes after they are superseded

## Current files

- AI_HANDOFF.md
- AI_STAGE_SUMMARY_2026-07-31.md
- PROJECT_NOTES.md

## Active docs (outside this folder)

For day-to-day operations and current system behavior, use:

- README.md
- DOCS_INDEX.md
- SYSTEM_OVERVIEW.txt
- OVERNIGHT.md
- CHANGELOG.md

## Archive rule

When moving a root-level doc here, keep filenames stable and update DOCS_INDEX.md so links stay accurate.
