# Historical Documentation Archive

This folder stores historical project handoff and summary documents.

## Purpose

Use this directory for documents that preserve implementation history or decision context but are not the current operational source of truth.

- AI handoff snapshots

and update both `DOCS_INDEX.md` and this inventory so status and links stay accurate.
