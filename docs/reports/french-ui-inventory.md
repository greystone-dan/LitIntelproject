## Recommended implementation approach

Use a message catalog keyed by stable IDs, with English as the source language and French values reviewed by a fluent Canadian French speaker. Resolve locale in this order: an explicit `?lang=fr` URL override, then `Accept-Language`, then English; include an accessible language toggle in the shared header. Keep placeholders named and consistent between locales, escape inserted text, and test catalog parity and English output compatibility.

The About-page proof of concept is intentionally limited. Its French values are machine-drafted and require fluent-speaker review; no legal terminology is represented as final.
